# 牛马鼓励器 · 薪动

让上班时的工资实时跳动，最小化后在桌面一角陪伴你。主要使用平台是 macOS，同时提供 Windows 版。

## 开始使用

**Mac** 用户可以从苹果菜单打开「关于本机」。如果「芯片」显示 Apple M 系列，选择 `mac-arm64.dmg` 结尾的文件。如果「处理器」显示 Intel，选择 `mac-x64.dmg` 结尾的文件。打开 DMG，把「牛马鼓励器」拖进「应用程序」，然后从那里启动。更新前，先在菜单栏的小牛菜单中选择「退出」。[下载最新版 Mac 安装包](https://github.com/ycycycycyyc/niuma-payday/releases/latest)

**Windows** 用户请先右键任务栏右下角的小牛图标，选择「退出」关掉旧版。小牛图标可能收在「显示隐藏的图标」里。在发布页选择 `windows-x64-portable.exe` 结尾的免安装版，或 `windows-x64-setup.exe` 结尾的安装版。[下载最新版 Windows 程序](https://github.com/ycycycycyyc/niuma-payday/releases/latest)

从源码运行：

需要 Node.js 22.12+ 和 npm。在项目目录运行：

```sh
npm ci
npm run setup:desktop
npm run dev
```

首次打开为演示模式。点击「设置我的月薪」，填写月薪、上下班时间和节假日地区，再保存。币种支持人民币、港币和美元，可以独立选择节假日地区，例如港币工资可以搭配中国大陆假期。发薪方式可直接选择，午休安排放在「更多偏好」中。

只预览网页界面可运行 `npm run dev:web`。独立浏览器预览可切换「浮窗」和「主界面」。在浮窗页可切换日光和夜色桌布、拖动玻璃卡片、调整外观，并查看工资、倒计时和小狗互动。运行 `node scripts/build-widget-preview.mjs` 会生成可离线打开的 `artifacts/preview/Niuma-Glass-Preview.html`。系统托盘和跨应用置顶由桌面版提供。

## 存钱记录板

在「薪动时刻」点「记入本月」，填好房租后，可以输入生活费查看本月能存多少钱，也可以输入想存的金额，反算还能花多少生活费。两项开支等于月薪时可存为零，超过月薪时显示超支。点「确认记入」后，结余或超支才计入「累计已存」。

展开「月度明细」可以补记以前的月份，也可以更正已有记录。同一个月只统计一次。新月份会带出最近一次以相同币种记录的房租和生活费，历月保留各自的月薪和支出。人民币、港币和美元分别累计。首页的「隐藏金额」同时遮住预算和明细。

记错月份时，可以在月度明细中撤回记录，确认后 15 秒内可撤销。撤回和撤销都会检查该月是否已被其他窗口修改。展开「存钱趋势」可查看所选币种最近最多 12 笔记录，超支显示在零线下方；「导出 CSV」导出截至本月的全部月度记录及币种。隐藏金额时，趋势数值、导出和修改操作一起收起。

## 摸鱼球馆

在「快乐实验室」点「来打乒乓球」，与电脑进行 11 分制休闲对战，领先 2 分获胜。每分由电脑发球，球先落电脑半台再落你的半台。接球时把球拍移到球后方，等球弹起，用鼠标或触控板向前挥过球。向左前方或右前方斜挥可打向两侧，轻推回球较短，快挥落点更深。键盘也可用方向键或 WASD 前后左右移动球拍。新一局开始前可选择电脑难度。

空格暂停或继续，Esc 收起游戏并返回工资页；切到后台、离开球馆或打开设置时自动暂停。当前局和历史成绩保存在本机，重开球馆后手动继续，不会补算离开期间的游戏时间。游戏默认静音，减少动态效果时保留必要球体运动并移除拖尾。

球馆中的预估收入只统计本次打开期间实际游玩的排班计薪时段，休息日、下班后和设置为暂停增长的午休不累计，切换币种后从零统计。游戏存档与工资、存钱账本分别保存。

## 计薪与工作日

- 月薪除以当月工作日数量，得到当月参考日薪，再按每天的有效工作时间实时增长。不同月份自动重新计算；完成本月所有班次后达到输入的月薪。
- 默认周一至周五工作，排除所选地区的公共假日。周六日（包括调休补班）默认休息，需要时点击首页「今天上班」；也可以手动设为「今天休息」或恢复日历安排。
- 午休默认不暂停。启用「午休暂停增长」后，完整日薪分摊到午休以外的工作时间。
- 发薪日默认每月最后一个工作日，跟随所选地区日历及手动日期安排；也可选每月 1 日或自定义 1–31 日。固定日期不因节假日顺延，小月没有该日期时取月末。发薪方式只影响倒计时。
- 下班早于上班时按跨夜班次计算，班次归属开始上班的日期，并使用该日期所属月份的参考日薪。所有时间使用电脑本地时区，地区选择只影响假日日历。
- 数字由当前时间和设置直接计算。电脑睡眠、关闭或再次打开应用后，会按时间重新计算，不依赖一直运行的计时器。
- 今日、本月和每周金额均为排班估算；修改月薪、日历或时间会重新计算当前展示，不是历史考勤或逐日工资账本。不计算个税、奖金、加班倍率或实际工资发放。
- 展开首页「月度排班」，可以提前安排补班、请假或休息，也可恢复某天的日历安排。编辑时预览计薪日数和参考日薪，点「保存排班」后生效；保存失败保留草稿，同日期被其他窗口修改时会提示冲突。跨夜班顶部显示班次开始日期，「本班休息」作用于这班，不会误改凌晨当天晚上的班次。
- 手动安排导致整月没有工作日时，月薪暂不分摊、增长为零；最后工作日发薪向后查找，未来 24 个月都没有工作日时显示暂无法确定。

升级旧日薪版本时，保留币种、节假日地区、班次、手动日期、目标与隐私偏好，请补填一次月薪，不按固定天数猜测换算。旧版已保存的发薪日期保留为固定日期；更早的月薪资料保留金额，确认设置后再开始计薪。

## 联网日历与缓存

中国大陆日历使用开源项目 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 按年整理的放假安排，**并非政府官方 API**。香港使用 [政府 1823 公众假期数据](https://www.1823.gov.hk/common/ical/sc.json)。

应用联网更新日历并保存在本机，更新失败时保留已有的有效缓存。大陆日历同时检查次年文件对 12 月的跨年修正；已确认过的修正不会因后续补充下载失败而回退。如果收入计算或最后工作日发薪涉及尚未确认的年份，会暂按周一至周五估算，并在首页提示。可手动更新日历，或通过「今天休息／今天上班」覆盖当天安排。

联网请求只获取公共日历，不上传工资、目标或个人设置。

## 浮窗、Mac 菜单栏与 Windows 托盘

- 在 Mac 上，点击菜单栏小牛图标，可以显示或隐藏工资浮窗、返回主窗口或退出应用。浮窗使用原生面板，点小狗和骨头按钮时可直接触发第一次点击。
- 想让当前应用盖住浮窗时，点浮窗工具栏的「将浮窗置底」。切回桌面还能看到她，点同一按钮即可重新置顶。浮窗被挡住或隐藏时，Mac 用户点击菜单栏的小牛，Windows 用户右键任务栏右下角的小牛，再选「将浮窗置顶」。右上角的「最小化浮窗」横线按钮会收起工资卡，留下桌面狗狗；双击狗狗恢复原位置的浮窗。
- 最小化后，狗狗会在屏幕可见范围内慢慢散步，轮流舔爪、玩球、打滚或睡觉。睡觉有蜷睡、侧躺和翻肚皮三种姿态，玩球采用 12 帧连续动作。动作前会收脚站稳，趴下、起身与转身使用独立过渡帧，完整做完一轮后再收尾，身体保持同一接地位置。按住狗狗拖到想让她待的位置，松手后她会从那里继续活动。鼠标经过或单击时她也会照常活动，双击可恢复原位置的工资卡。狗狗以外的透明区域仍可点击。托盘的「隐藏工资浮窗」会把狗狗也一起收起。

- Windows、macOS 和网页共用同一个浮窗组件。标准卡片为 376 × 200 逻辑像素，卡片内只保留工资和倒计时，上沿保留小狗。浮窗和设置页使用随应用提供的本地圆体字。
- 点齿轮打开「浮窗设置」，可在 85%–150% 之间等比例调整大小，选择预设底色，或用全色色轮、亮度和十六进制色值选色。不透明度可调为 15%–100%，默认底色为淡粉色 `#F9DFEB`、不透明度为 36%。调整后自动保存，也可恢复默认；外观设置不改变主界面的颜色和尺寸。
- 玻璃弧形边缘保留反光。浏览器演示对同页桌布做折射；独立桌面浮窗透出其他窗口原本的内容，不需要屏幕录制权限。

- 点上沿的小狗，她会坐下、伸爪握手，再起身散步。在 Mac 或 Windows 桌面版点骨头，她会跑出浮窗，追上鼠标旁的骨头后坐下笑。移动骨头，她会起身再追。可以照常点她身后的应用。再点骨头、从小牛菜单选「收起骨头」，或在浮窗有焦点时按 Esc，她会跑回卡片当前的位置，接着散步。即使工资卡已经置底，追逐和返程中的小狗仍临时置顶，落回上沿后再跟随卡片层级。
- 仅当小狗在浮窗上沿活动时，鼠标移到她身上才会出现图片食物菜单，可选「喂狗粮」或「喂棒棒」。进食时暂停当前活动，吃完后继续。追逐骨头、返程和最小化后的桌面陪伴状态不显示喂食菜单，回到浮窗上沿后恢复。
- 网页预览中的小狗也可离开卡片，在卡片外的页面区域追逐骨头。最小化后保留陪伴小狗，双击她恢复工资卡；活动范围限于网页，不会进入其他应用。
- 开启系统「减少动态效果」后，小狗会停止自动巡游和陪伴动作，仍可使用握手、骨头互动与双击恢复浮窗。
- 开启「上班自动出现浮窗」后，应用在后台运行时，在工作时段自动显示置顶小窗；自动出现的小窗在下班后收起。主界面正在显示时不会再弹出一个小窗抢占空间。
- 关闭浮窗或返回主界面后，同一班次不会反复自动弹出。下一班次可自动出现。
- 可以随时点击「开启悬浮窗」或使用托盘菜单手动显示，包括休息日。手动显示浮窗本身不更改当天计薪安排；补班需另点「今天上班」。
- 拖动小窗空白区域可移动；位置会保存，显示器变化时自动校正到可见区域。
- 关闭主窗口会收起到系统托盘，保持后台运行。要完全退出，使用托盘菜单「退出」。如果系统托盘不可用，关闭主窗口则退出。
- 自动浮窗要求应用仍在运行；**本版本不会设置开机或登录自动启动**。应用完全退出或电脑关机时无法自动显示。

还有每日小目标、咖啡／餐饭换算、带薪休息计时、鼓励语和成就展示。主界面的金额隐藏按钮会同时隐藏主界面和浮窗中的金额，浮窗不再单独显示眼睛按钮。

## 数据保存

无需账号。桌面版的工资设置、月度存钱记录、手动日期安排和日历缓存保存在 Electron `userData` 目录的 `state.json`，浮窗位置、大小、底色和不透明度保存在 `desktop.json`。网页预览使用浏览器本地存储，两者独立。

首页底部的「资料备份与恢复」可导出 JSON，导入时先展示月薪、记录数和排班数，核对确认后替换本机资料。导入前保留现有有效资料，预览期间如果有新资料保存，本次导入会停止。备份文件包含实际工资和存款金额，游戏进度与浮窗外观不包含在内。

应用自动轮换最近 3 份有效资料存档。读取异常时先保留原文，再尝试恢复有效存档；无法保护原文件时停止写入。恢复提示会出现在备份区域，请核对恢复后的工资与记录。原生文件使用临时文件和替换保存，网页使用本地存储；这些措施不能代替设备之外的个人备份。

主窗口或工资浮窗的渲染进程异常退出时自动重载一次；再次失败时，从托盘或菜单栏选择对应的恢复入口。锁屏或睡眠时停止桌宠和浮窗鼠标轮询，恢复后重新调度。Windows 开启减少动态效果且桌宠静止时降低轮询频率；正常移动和拖动保持原有响应频率。

渲染进程使用沙盒和上下文隔离，关闭 Node.js 集成；桌面操作通过限定的 preload 接口执行，并校验 IPC 请求窗口。

## 测试与构建

```sh
npm test
npm run build
npm run test:ui
npm run pack
```

`test:ui` 使用系统已安装的 Google Chrome，以无头模式检查设置、金额增长、隐私、假日覆盖和移动布局。`pack` 目标为当前平台的未安装应用目录，输出到 `release/`。可按目标平台构建安装包：

```sh
# Windows x64
npm run build
npx electron-builder --win --x64 --publish never

# macOS Apple Silicon（在 macOS 上执行）
npm run build
npx electron-builder --mac dmg zip --arm64 --publish never

# macOS Intel（在 macOS 上执行）
npx electron-builder --mac dmg zip --x64 --publish never
```

在 GitHub 手动运行 `Desktop builds` 时，默认分别使用 Windows x64、Apple Silicon 和 Intel Mac 构建机。Mac 任务校验 DMG 和 ZIP 的架构及签名，再从交付 ZIP 中启动应用；Windows 任务从交付免安装程序中解出应用。三个任务检查打包后的主界面、浮窗、外观保存和陪伴流程，Windows 另用系统鼠标检查喂食。1.6 新增 Mac WindowServer 系统鼠标用例，检查移入后立即按下、拖动、双击恢复和两种喂食；本地 Windows 无法执行这些用例，结果须以该版本的 Mac CI 记录为准。当前 Mac 包使用供内部测试的本地签名（ad-hoc），尚未通过 Apple 公证。
