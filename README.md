# 牛马鼓励器 · 薪动

让上班时的工资实时跳动，最小化后在桌面一角陪伴你。主要使用平台是 macOS，同时提供 Windows 版。

## 开始使用

**Mac** 用户可以从苹果菜单打开「关于本机」。如果「芯片」显示 Apple M 系列，选择 `mac-arm64.dmg` 结尾的文件。如果「处理器」显示 Intel，选择 `mac-x64.dmg` 结尾的文件。打开 DMG，把「牛马鼓励器」拖进「应用程序」，然后从那里启动。更新前，先在菜单栏的小牛菜单中选择「退出」。[Mac 安装包（私有仓库）](https://github.com/ycycycycyyc/niuma-payday/releases/tag/macos-v1.1.1)

**Windows** 用户可双击 `Niuma-1.1.0-windows-x64-portable.exe`。如已运行旧版，请先从系统托盘的牛马鼓励器菜单选择「退出」。

从源码运行：

需要 Node.js 22.12+ 和 npm。在项目目录运行：

```sh
npm ci
npm run setup:desktop
npm run dev
```

首次打开为明确标注的演示模式。点击「设置我的日薪」，填写日薪、上下班时间和节假日地区，再保存。币种支持人民币、港币和美元；币种仅用于显示，不做汇率换算。午休和发薪日放在「更多偏好」中。

只预览网页界面可运行 `npm run dev:web`。独立浏览器预览可切换「浮窗」和「主界面」。在浮窗页可切换日光和夜色桌布、拖动淡粉玻璃卡片，观察小牛、工资和倒计时。运行 `node scripts/build-widget-preview.mjs` 会生成可离线打开的 `artifacts/preview/Niuma-Glass-Preview.html`。系统托盘和跨应用置顶由桌面版提供。

## 计薪与工作日

- 每个工作日按输入的日薪计入，数字随当天工作进度增长，到下班时达到完整日薪。
- 默认周一至周五工作，排除所选地区的公共假日。周六日（包括调休补班）默认休息，需要时点击首页「今天上班」；也可以手动设为「今天休息」或恢复日历安排。
- 午休默认不暂停。启用「午休暂停增长」后，完整日薪分摊到午休以外的工作时间。
- 下班早于上班时按跨夜班次计算，班次归属开始上班的日期。所有时间使用电脑本地时区，地区选择只影响假日日历。
- 数字由当前时间和设置直接计算。电脑睡眠、关闭或再次打开应用后，会按时间重新计算，不依赖一直运行的计时器。
- 今日、本月和每周金额均为排班估算；修改日薪或时间会重新计算当前展示，不是历史考勤或逐日工资账本。不计算个税、奖金、加班倍率或实际工资发放。

从旧月薪版本读取设置时，会回到演示模式，要求重新填写日薪，避免把月薪误当成日薪。

## 联网日历与缓存

中国大陆日历使用开源项目 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 按年整理的放假安排，**并非政府官方 API**。香港使用 [政府 1823 公众假期数据](https://www.1823.gov.hk/common/ical/sc.json)。

应用联网更新日历并保存在本机，更新失败时保留已有的有效缓存。如果对应年份尚未公布、下载失败且没有有效缓存，会暂按周一至周五估算，并在首页提示。可手动更新日历，或通过「今天休息／今天上班」覆盖当天安排。

联网请求只获取公共日历，不上传工资、目标或个人设置。

## 浮窗、Mac 菜单栏与 Windows 托盘

- 在 Mac 上，点击菜单栏小牛图标，可以显示或隐藏工资浮窗、返回主窗口或退出应用。浮窗使用原生面板，点小狗和骨头按钮时可直接触发第一次点击。

- Windows、macOS 和网页共用同一个浮窗组件。标准卡片为 376 × 200 逻辑像素，小牛为 92 × 92，下班倒计时使用 31 像素的等宽数字。主界面工资卡和玻璃采用从参考图取样的淡粉色 `#FDEDF4`。玻璃中央用 13% 不透明度，弧形边缘保留反光。浏览器演示对同页桌布做折射；独立桌面浮窗透出其他窗口原本的内容，不需要屏幕录制权限。

- 点上沿的小狗，她会坐下、伸爪握手，再起身散步。点骨头按钮可以拿起骨头，让她沿卡边追着鼠标跑。再点一次按钮，或在浮窗获得焦点时按 Esc，即可收起骨头。透明留白可点击后面的窗口。
- 开启系统「减少动态效果」后，小狗会停止自动巡游，仍可使用握手与骨头互动。
- 开启「上班自动出现浮窗」后，应用在后台运行时，在工作时段自动显示置顶小窗；自动出现的小窗在下班后收起。主界面正在显示时不会再弹出一个小窗抢占空间。
- 关闭浮窗或返回主界面后，同一班次不会反复自动弹出。下一班次可自动出现。
- 可以随时点击「开启悬浮窗」或使用托盘菜单手动显示，包括休息日。手动显示浮窗本身不更改当天计薪安排；补班需另点「今天上班」。
- 拖动小窗空白区域可移动；位置会保存，显示器变化时自动校正到可见区域。
- 关闭主窗口会收起到系统托盘，保持后台运行。要完全退出，使用托盘菜单「退出」。如果系统托盘不可用，关闭主窗口则退出。
- 自动浮窗要求应用仍在运行；**本版本不会设置开机或登录自动启动**。应用完全退出或电脑关机时无法自动显示。

还有每日小目标、咖啡／餐饭换算、带薪休息计时、鼓励语和成就展示。金额隐藏按钮会同时隐藏主界面和浮窗中的金额。

## 数据保存

无需账号。桌面版的工资设置、手动日期安排和日历缓存保存在 Electron `userData` 目录的 `state.json`，浮窗位置保存在 `desktop.json`。网页预览使用浏览器本地存储，两者独立。

渲染进程使用沙盒和上下文隔离，关闭 Node.js 集成；桌面操作通过限定的 preload 接口执行，并校验 IPC 请求窗口。

## 测试与构建

```sh
npm test
npm run build
npm run test:ui
npm run pack
```

`test:ui` 使用系统已安装的 Google Chrome，以无头模式检查设置、金额增长、隐私、假日覆盖和移动布局。`pack` 目标为当前平台的未安装应用目录，输出到 `release/`。可按目标平台构建安装包：

```sh
# Windows x64
npm run build
npx electron-builder --win --x64 --publish never

# macOS Apple Silicon（在 macOS 上执行）
npm run build
npx electron-builder --mac dmg zip --arm64 --publish never

# macOS Intel（在 macOS 上执行）
npx electron-builder --mac dmg zip --x64 --publish never
```

在私有仓库手动运行 `Desktop builds` 时，默认分别使用 Apple Silicon 和 Intel 的 macOS 构建机。每个任务校验 DMG 和 ZIP 的架构及签名，再从交付 ZIP 中启动应用做原生测试。当前 Mac 包使用供内部测试的本地签名（ad-hoc），尚未通过 Apple 公证。
